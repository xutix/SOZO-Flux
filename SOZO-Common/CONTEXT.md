# SOZO Flux 统一术语

本文件只定义产品和系统中的词汇，不记录实现方案。

- **协调器（Coordinator）**：空间系统的权威节点。它维护空间灯光场景、节点登记和控制授权；当前由 ESP32-S3 主设备承担。
- **扩展节点（Extension Node）**：加入 SOZO 空间的独立设备。它可以提供灯光输出、按钮、旋钮、传感器或其组合；当前 ESP32-C3 灯带属于扩展节点。
- **控制来源（Control Source）**：产生控制意图的来源，例如网页、串口、Wi-Fi 节点、ESP-NOW 节点、BLE 实体控制器、语音或电脑音频。
- **控制命令（Control Command）**：来源明确、已经校验、请求改变空间状态的意图。只有控制命令可以改变权威场景。
- **场景（Lighting Scene）**：对灯效、颜色、亮度和效果参数的完整渲染意图。它不包含某个节点的 GPIO、物理长度或私有硬件配置。
- **场景版本（Scene Revision）**：协调器单调递增的场景编号，用来识别重复、过期和已应用的场景。
- **逻辑灯珠（Logical LED）**：参与灯效计算的灯珠位置。灯效只认识逻辑灯珠。
- **物理灯珠（Physical LED）**：实际连接在一条数据线上的灯珠位置。它可能多于逻辑灯珠。
- **灯珠几何（LED Geometry）**：逻辑灯珠与物理灯珠的数量、方向和映射关系。
- **灯光帧（Lighting Frame）**：一次渲染产生的完整逻辑 RGB 结果。
- **跟随主灯（Follow Main）**：扩展灯光节点使用协调器发布的场景，在本地持续渲染。
- **独立模式（Independent）**：扩展灯光节点维护自己的场景；协调器只向它发送明确的目标控制命令。
- **链路状态（Link State）**：传输层对连接是否建立、认证、断开或重连的事实描述。
- **命令回执（Command Receipt）**：节点针对一次可确认命令返回的接受、拒绝或已应用结果。它证明命令处理结果，不等同于链路状态。
- **状态快照（Status Snapshot）**：节点按请求或诊断策略返回的运行状态，例如已应用场景版本、可用内存和本地错误码。
- **健康检测（Health Probe）**：为诊断目的发起的独立健康检查。它不是灯效刷新的一部分，也不是普通链路连接的前提。
- **SozoBus**：SOZO 自己实现的轻量消息总线，借鉴节点、主题和请求/响应思想；它不是 ROS 2、DDS 或 micro-ROS。
