# SOZO Flux 统一术语

本词汇表定义 SOZO Flux 在空间控制、节点和灯光领域中的统一语言。设备型号只描述部署位置，不决定业务地位。

## 空间控制

**Flux Hub**：
承载空间协调角色和控制入口的设备。它可以提供本地能力，但这些能力不构成系统权威。
_Avoid_：主灯、主设备

**协调器（Coordinator）**：
维护权威空间场景、节点登记和控制授权的软件角色。

**控制来源（Control Source）**：
产生控制意图的参与者，例如网页、实体控制器、语音或桌面软件。

**控制命令（Control Command）**：
来源明确、已经校验、请求改变空间状态的意图。

**空间场景（Space Scene）**：
协调器发布给灯光节点的权威渲染意图，包含灯效、颜色、亮度和效果参数，不包含节点私有硬件配置。

**业务场景（Experience Scene）**：
面向用户的高层行为，例如专注或游戏；它可以协调灯光、音频和其他设备能力，不等同于单个灯效。

**场景版本（Scene Revision）**：
协调器为每次空间场景变化产生的单调递增编号。

## 节点

**扩展节点（Extension Node）**：
加入 SOZO 空间并声明一种或多种能力的独立参与者。

**灯光节点（Light Node）**：
拥有灯光输出能力、在本地渲染场景并维护自己硬件配置的节点。

**本地灯光节点（Local Light Node）**：
与 Flux Hub 部署在同一硬件上的灯光节点；它与远程灯光节点遵循相同的场景语义。
_Avoid_：主灯

**远程灯光节点（Remote Light Node）**：
通过节点链路接入 Flux Hub 的灯光节点。
_Avoid_：副设备、副灯

**跟随空间场景（Follow Space）**：
灯光节点持续采用协调器发布的空间场景。
_Avoid_：跟随主灯、同步主灯

**独立模式（Independent）**：
灯光节点采用自己的本地场景，直到明确恢复跟随空间场景。

**节点本地配置（Node-local Configuration）**：
只属于一个节点的物理灯珠数量、方向、映射和启动行为，不属于空间场景。

**节点绑定（Node Binding）**：
Flux Hub 将已认证设备登记为 SOZO 空间节点的关系。

## 灯光渲染

**灯效（Effect）**：
把场景参数转换为灯光帧的渲染算法，例如呼吸、彩虹或流星。

**逻辑灯珠（Logical LED）**：
参与灯效计算的灯珠位置。

**物理灯珠（Physical LED）**：
实际连接在一个灯光节点输出端的灯珠位置。

**灯珠几何（LED Geometry）**：
一个灯光节点内逻辑灯珠与物理灯珠的数量、方向和映射关系。

**灯光帧（Lighting Frame）**：
一次渲染产生的完整逻辑 RGB 结果。

**音频帧（Audio Frame）**：
供灯光节点消费的标准化音量、RMS、鼓点和可用性数据。

## 节点通信

**命令回执（Command Receipt）**：
节点对一次可确认命令返回的接受、拒绝或已应用结果。

**状态快照（Status Snapshot）**：
节点公开的已应用场景版本、能力和健康事实。

**SozoBus**：
SOZO Flux 的轻量类型化消息总线，不是 ROS 2、DDS 或 micro-ROS。
